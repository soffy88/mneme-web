# Aria 视觉资源

| 文件 | 用途 |
|------|------|
| `playing.jpg` / `conversation.jpg` | 全景照片模式 |
| `face-front.jpg` / `face-play.jpg` | Hybrid 照片脸贴图 |
| `aria.vrm` | 默认 VRM 身体（CC0 · 100Avatars R1「Olivia」） |
| `aria-alt.vrm` | 备选 VRM（CC0 ·「Jennifer」） |

## 许可

- **Olivia / Jennifer VRM**：来自 [100Avatars R1](https://github.com/ToxSam/open-source-avatars)（Polygonal Mind），**CC0**。
- 脸部/全景静图：产品生成资产，仅用于善学记 Aria。

## 替换角色

将新的 `.vrm` 放到本目录并命名为 `aria.vrm`，或改 `AriaVRM.tsx` 中的 `VRM_URL`。
需为人形 VRM 0.x/1.x（含 humanoid 骨骼）。
